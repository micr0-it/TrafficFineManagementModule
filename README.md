# Trafik Cezası Yönetim Modülü

Şirket araçlarına ait trafik cezalarının sisteme girilmesi, çok aşamalı onay
sürecinden geçirilmesi ve işlem geçmişinin takip edilmesi için geliştirilmiş
bir ASP.NET Core MVC uygulaması.

## Teknolojiler

- .NET 9, ASP.NET Core MVC
- Entity Framework Core
- SQL Server

## Mimari

N-katmanlı mimari:

- **EntityLayer**: Entity sınıfları ve enum'lar
- **DataAccessLayer**: DbContext, generic repository ve EF Core DAL sınıfları
- **BusinessLayer**: İş kuralları ve onay akışı
- **WebUI**: MVC controller'lar ve view'lar
